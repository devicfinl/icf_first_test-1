## Components
- **Buttons:** Primary, Secondary, Destructive
- **Cards:** 12px border radius, subtle shadow
- **Forms:** labeled inputs, inline validation errors

## UX requirements
- Mobile responsive (test at 375px, 768px, 1440px)
- Loading states on all async actions
- Empty states (no events yet, no posts yet, no media yet)
- Error states (failed fetch, validation errors)
- Accessible forms (labels, keyboard navigation, focus states)
