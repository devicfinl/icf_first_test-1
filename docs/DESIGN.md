# Design System

## Design Direction

The UI should feel:

- Modern
- Professional
- Warm
- Community-oriented
- Calm
- Trustworthy
- Clean and approachable

The visual identity should be built around the provided brand color palette.

Do not introduce a different visual style unless explicitly requested.

The design should feel like a cohesive product, not a collection of independently generated AI screens.

---

## Color System

Use the following colors as the primary visual foundation.

### Brand Colors

| Name | Hex | Usage |
|---|---|---|
| Primary Navy | `#142C50` | Primary brand color, headers, navigation, primary actions |
| Warm Brown | `#9C5722` | Secondary brand color, highlights, secondary actions |
| Sand | `#CFB390` | Supporting backgrounds, badges, accents |
| Cream | `#F5EDE3` | Main warm background and soft surfaces |

### Semantic Colors

Use semantic colors only when required by the meaning of the UI.

| Purpose | Color |
|---|---|
| Success | `#16A34A` |
| Error | `#DC2626` |
| Warning | `#D97706` |
| Info | `#2563EB` |

Semantic colors must not replace the brand palette for normal UI decoration.

---

## Color Usage Rules

### Primary Navy — `#142C50`

Use for:

- Primary buttons
- Main navigation
- Important headings
- Active navigation states
- Important links
- Brand elements
- Primary interactive elements

### Warm Brown — `#9C5722`

Use for:

- Secondary actions
- Highlights
- Supporting interactive elements
- Important accents
- Selected states where appropriate

### Sand — `#CFB390`

Use for:

- Secondary backgrounds
- Badges
- Decorative accents
- Supporting UI elements

### Cream — `#F5EDE3`

Use for:

- Page backgrounds
- Section backgrounds
- Soft cards/surfaces
- Empty-state backgrounds

### Important

Do NOT randomly introduce additional brand colors.

Do NOT replace the palette with:

- Purple
- Indigo
- Generic blue
- Bright gradients
- Neon colors
- AI-generated color combinations

If another color is required, use a neutral or semantic color only when there is a clear UX reason.
